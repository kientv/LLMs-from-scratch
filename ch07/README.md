# Chương 7: Finetuning to Follow Instructions

&nbsp;
## Mã chính của chương

- [01_main-chapter-code](01_main-chapter-code) chứa mã chính của chương and exercise solutions

## Tài liệu bổ sung

- [02_dataset-utilities](02_dataset-utilities) chứa utility code that can be used for preparing an instruction dataset
- [03_model-evaluation](03_model-evaluation) chứa utility code for evaluating instruction responses using a local Llama 3 model and the GPT-4 API
- [04_preference-tuning-with-dpo](04_preference-tuning-with-dpo) implements code for preference finetuning with Direct Preference Optimization (DPO)
- [05_dataset-generation](05_dataset-generation) chứa mã to generate and improve synthetic datasets for instruction finetuning
- [06_user_interface](06_user_interface) implements an interactive user interface to interact with the pretrained LLM
